# W0002: Path Import Not Resolved

An `import { ... } from "./other.star";` or similar statement was not resolved during type-checking, either because of a module resolution error or because the file was type-checked in single-file mode. Attempting to use the imported names will error.

## Example

```starstream
// playground.star
import { add } from "./helpers/math.star";  // W0002 here

fn main() -> i64 {
    add(2, 3)  // E0001 "unknown variable" because the import was ignored
}
```

## Fix

Fix the previous module resolution error, or compile from the command-line without single-file mode:

```sh
starstream wasm -c entry.star
```
