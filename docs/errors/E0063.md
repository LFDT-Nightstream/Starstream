# E0063: Namespace already defined

You imported or declared a namespace with a name that is already used by
another namespace in this module (from an earlier namespace import, an `enum`,
`utxo`, or `token` definition, or the built-in prelude).

## Example (error)

```starstream
import ns from starstream:std/cardano;
import ns from starstream:std/ledger;
```

## Fix

Give each namespace import or definition a distinct name:

```starstream
import cardano from starstream:std/cardano;
import ledger from starstream:std/ledger;
```
