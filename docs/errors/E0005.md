# E0005: Unary Operator Type Mismatch

You used a unary operator with the wrong type.

## Example

```starstream
fn main() {
    let x = -true;  // Error: unary `-` expects a signed integer type but found `bool`
}
```

```starstream
fn main() {
    let x: u8 = -1;  // Error: unary `-` expects a signed integer type but found `u8`
}
```

```starstream
fn main() {
    let x = !42;  // Error: unary `!` expects type `bool` but found `i64`
}
```

## How to fix

Use the correct type for the operator:

```starstream
fn main() {
    let x = -42;    // OK: negating a signed integer
    let y = !true;  // OK: logical not on a boolean
}
```
